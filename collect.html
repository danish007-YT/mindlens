Use the MongoDB data for ML training

On the machine with access to the same database, export the stored samples into the format already used by this project:

python ml/export_from_mongo.py --output collected-data

Then run the existing preprocessing/training workflow, for example:

python ml/pipeline.py --collected collected-data --work ml-work

Audio is exported as WebM and expression images retain their labels, so the existing conversion, augmentation, and training scripts can use them.

Notes

  • Run this page in a modern browser. For full camera/audio access, use HTTPS or open it from localhost.
  • Captured files are saved only when you select Upload sample to MongoDB. Use the uploaded-dataset list above to confirm what reached the database.
  • See DATA_COLLECTION_README.md for the full consent, storage and processing guidance.
